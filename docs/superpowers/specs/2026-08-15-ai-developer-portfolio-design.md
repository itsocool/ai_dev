# AI Developer Portfolio Landing Page Design

## Goal

Create a polished single-page portfolio for an AI developer. The primary audience is recruiters, and the primary conversion is an interview or contact request. All profile and project copy is clearly replaceable example content.

## Visual Direction

Use an editorial technology aesthetic: warm ivory background, charcoal typography, and a single vivid blue accent. Favor large type, strong alignment, generous whitespace, and a few substantial compositions over decorative cards, neon effects, or generic AI imagery.

## Page Structure

1. A compact header with the example developer name and anchor links to Work, About, and Contact.
2. A high-impact hero with the headline “AI를 실제 제품으로 만드는 개발자”, a concise introduction, core capability text, and a primary “면접 제안하기” contact action.
3. Three large horizontal project case studies. Each includes the problem, role, technology, and clearly labeled example outcome.
4. An About and capabilities section focused on applied AI engineering, product delivery, and collaboration.
5. A full-width blue contact section with a `mailto:` interview/contact action.
6. A minimal footer.

## Content

Use Korean example content and an obviously fictional example identity and email address. Avoid unsupported claims presented as real credentials. Keep all content directly in the HTML so it is easy to replace.

## Implementation

The repository is empty, so use dependency-free semantic HTML and CSS. No framework, build step, JavaScript, form backend, animation library, icon package, or external image is required. Navigation uses native anchors and contact uses `mailto:`.

The layout must remain readable at desktop and mobile widths. Use visible keyboard focus styles, sufficient contrast, semantic landmarks, descriptive links, and reduced-motion-safe CSS.

## Verification

Run the site through a local static server. Verify the final browser rendering at desktop and mobile widths, navigation anchors, contact link, overflow, typography, and keyboard focus. Compare the implementation against the approved visual concept before handoff.
